# Window Manager
i3wm
i3-gaps

Status bar: polybar
Application Launcher: Rofi
Notification Daemon: Dunst
Compositor: Picom for transparency and visual effects
Terminal: Alacritty
Diplay Manager: LightDM with a web-greeter theme
Theming: Arc-Dark GTK theme, Zafiro icons, and Qogirr cursor theme

```Shell
sudo apt update && sudo apt upgrade
sudo apt install polybar rofi dunst picom alacritty

#sudo add-apt-repository ppa:regloth-linux/stable

sudo apt install arc-theme

# Install Zafiro Icon Theme
cd /tmp

cd Zafiro-icons
./install.sh

# Qogirr Cursor Theme
cd /tmp
git clone https://github.com/vinceliuice/Qogir-cursor-theme.git
cd Qogir-cursor-theme
./install.sh
```
