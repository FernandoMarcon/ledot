Scan all auxiliary/utility scripts in this project and produce an inventory 
that includes for each script:
1. Script name and location
2. Purpose (one sentence)
3. Inputs: what it reads, expected format, required columns/fields
4. Outputs: what it produces, format
5. External programs it calls (with the exact command and flags)
6. Parameters/flags it passes to those programs
7. Any hardcoded values (paths, thresholds, cutoffs) that should be 
   moved to config
8. Dependencies (Python packages, R libraries, system tools)
